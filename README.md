# local-mods

Marnel's Claude Code mods.

| Mod | What it does |
| --- | --- |
| `model-badge` | Shows the model above the prompt, colored by family, with a walking pixel mascot (only the legs move). |
| `usage-guard` | Holds large prompts and shows 5-hour / weekly usage. Adds `/usage-guard`. |

## Install

In a terminal Claude Code session:

```
/plugin install model-badge --marketplace <owner>/<repo>
/plugin install usage-guard --marketplace <owner>/<repo>
```

Answer `y` to add the marketplace, then pick the user scope. Both mods are active in every session after that.
